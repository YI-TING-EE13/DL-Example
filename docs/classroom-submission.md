# Classroom submission — compatibility link

The maintained PR description format is `student/STUDENT_SUBMISSION.md` in the instructor-provided Git course package. After completing your PR, save Task branch, Contribution commit SHA, PR URL, Content answer and Location answer together in its description. Answer: “What did your commit record, and why?” and “Where is your commit now?”

If you cannot complete the push or pull request, stop and ask your instructor for help. Keep your changes and the error message. Once the issue is resolved, complete your pull request, after class if needed. No extra submission document is required. Teachers may track unfinished progress internally. A blocked operation is not a completed PR, and opening a PR does not by itself pass the two understanding checks. Review, merge and CI permission remain separate decisions. See the [minimal entry](classroom-notes/README.md), then follow the full course materials.
