# Classroom submission — compatibility link

The maintained blank format is `student/STUDENT_SUBMISSION.md` in the instructor-provided Git course package. Save Task branch, Contribution commit SHA, PR URL, Content answer and Location answer together after answering: “What did your commit record, and why?” and “Where is your commit now?”

If no contribution commit exists use `N/A - commit pending`; if no PR exists use `N/A - publication pending`. Keep any real SHA/URL. With publication blocked, privately hand in the same fields plus last step/error/reason through the agreed course route. Actual push success and PR creation are different states; teacher receipt, correctness and merge are separate. See the [minimal entry](classroom-notes/README.md), then follow the full course materials.
